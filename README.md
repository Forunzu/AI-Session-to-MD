# 会话转 MD

把 Claude CLI 与 Codex 的会话记录（JSONL）转换成 Markdown 归档，带图形界面：
浏览会话 → 预览内容 → 按重要程度逐条选导出模式 → 批量 / 单条导出。

## 下载

绿色单文件版在 [Releases](../../releases) 里下载 `ChatToMD.exe`（约 21MB，免安装，双击即用）。
运行时仅依赖系统 **WebView2 运行时**（Win10/11 多数自带，随 Edge 提供）。

## 功能

- **自动读取**：启动即扫描默认目录（支持 `CLAUDE_CONFIG_DIR` / `CODEX_HOME` 环境变量），无需手动加载。
- **自定义来源**：会话不在默认位置时，可在「来源目录」里添加任意文件夹，自动识别 Claude / Codex 格式。
- **三种导出模式**（可逐条设置，也可批量设置）：
  - `纯对话`：只留你与 AI 的正文
  - `对话+工具`：正文 + 工具调用 / 命令 / 结果（默认）
  - `完整原始`：含思考、系统消息等全部内容
- **筛选与搜索**：按来源筛选、按标题/项目/日期搜索。
- **会话目录（📑）**：预览区右侧列出整场对话的导航条目 —— 每条你的指令 + 每轮 AI 的首条回复，
  🧑/🤖 分色区分，可切「全部 / 只看我 / 只看 AI」，点条目跳到正文，滚正文时高亮跟随。
  CLI 自己写进会话的本地命令回显（`/model`、登录提示等）不算指令，正常模式直接隐藏，
  只在「完整原始」里折叠展示。
- **输出目录自选**：导出到你指定的目录，按 `claude/` `codex/` 分类，文件名为 `日期_标题.md`。

## 迁移（🔀）

顶部「🔀 迁移」按钮，两种模式：

### 1. 跨 CLI 续聊

把一个聊到一半的会话搬到另一个 CLI 里接着聊，不用手动复制粘贴。也可在预览标题栏点「↪ 迁移」直接迁当前会话。

- **原生续聊**：直接生成目标 CLI 自己的会话文件
  - Claude → `~/.claude/projects/<项目slug>/<新sessionId>.jsonl`，之后先 `cd <项目目录>`、再 `claude --resume <会话 id>`
  - Codex → `~/.codex/sessions/年/月/日/rollout-….jsonl`，之后 `codex -C "<项目目录>" resume <会话 id>`
    （**收的是 id 不是路径**；传路径会报 `No saved session found with ID …`。忘了 id 就用
    `codex resume --all` 从列表挑，`--all` 关掉默认的按当前目录过滤）
  - 给出的命令一律**不用 `&&` 连接**：Windows PowerShell 5.1 会报「标记"&&"不是此版本中的有效语句分隔符」，
    而 cmd.exe 又不认 `;`。Codex 用根命令的 `-C/--cd`（写在 `resume` 前面）一行搞定；Claude 没有这类参数，
    所以给两行、分别回车执行。
- **通用交接包**：任何 CLI 都能用。生成 `handoff_<标题>_<日期>/`，内含 `会话记录.md` + `交接提示词.txt`，
  把提示词整段粘进目标 CLI 即可。
- **携带范围**：全部轮次 / 最近 N 轮（默认 20）/ 字符上限（默认 6 万，从尾部保留）。
- 首轮会自动插入一段交接说明（来源 CLI、原标题、原项目目录、总轮数与保留轮数）。
- 工具活动折叠成 `〔工具 …〕` 文本，**不生成真实的 tool_use / tool_result 块** —— 缺配对的结果块会让目标 CLI 下一轮直接报错。
- 只新建文件，不改动任何已有会话。

### 2. 备份 / 还原（换电脑）

纯文件级搬运，与会话格式无关，所以能一次覆盖本机装的**全部** AI CLI（自动探测 `~/.*` 下的 CLI 目录，
另可手动添加自定义目录）。

- **范围三选一**：仅会话数据 / 整个根目录（智能排除）/ 完整不排除。
  智能排除会跳掉 `downloads`、`cache`、`logs_*.sqlite*`、`backup-*`、`shell-snapshots` 这类可再生的大件
  —— 本机实测 `.claude` 742 MB → 399 MB、`.codex` 7.7 GB → 3.1 GB。
- **干跑先行**：备份/还原都先出「多少文件 / 多少体积 / 多少可跳过 / 最大的几个」清单，确认后才真跑；
  大任务走后台线程 + 进度条，可随时取消。
- **凭证文件**（`~/.claude/.credentials.json`、`~/.codex/auth.json`）默认包含，换机后免重新登录；
  可逐行关掉。备份盘或云盘泄露等于账号泄露，自行权衡。
- **每次备份自成一个带日期的快照目录**：在你选的目录下新建 `claude_20260903-1930\`（只备一个 CLI 时用它的
  名字，多个则用 `AI-CLI-Backup_20260903-1930\`），`manifest.json`、`备份说明.txt` 和各 CLI 子目录**都在这一层**，
  整目录搬走即可。干跑清单里会写明落盘位置。
  想增量更新上次那份，把目标**直接选到那份备份**（有 `manifest.json` 的那一层），不会再套一层。
- **增量**：同名同大小同修改时间（±2s）的文件直接跳过，重复备份很快。
- `备份说明.txt` 是给人看的：备份时间、来源机器、来源 HOME、是否含凭证、包含哪些 CLI、目录结构、五步还原流程。
- 可选备份完打包 zip：放在快照目录的**同级**，包内**套一层同名文件夹**（`claude_20260903-1930/manifest.json` …），
  解压后不会把 `manifest.json` 散到解压目录外面；打包失败也不影响已复制好的文件。
- **还原端认路很宽**：选 `manifest.json` 所在那层最稳，选它的**上一层**或里面的**某个 CLI 子目录**都会自动归位；
  `manifest.json` 被手动挪进了 CLI 子目录也能认出来。zip 直接选，会先解到临时目录。
  一个目录下同时放了多份备份时不猜，直接报「下面有 N 份备份（…），请直接选中要还原的那一份」。
  预览为 0 个文件时会说明原因（期望看到 `root\` / `home\` 子目录），并且不允许直接开跑。
- **还原只增不删**：同名文件按策略跳过或覆盖，覆盖前先存 `.bak-<时间戳>`；目标端多出来的文件一律不动。
- **路径改写**（默认关，勾选后生效）：换机时项目目录变了（如 `E:\在办项目` → `D:\Projects`），
  一次改到四处 —— `projects/<slug>/` 目录名、JSONL 每行的 `cwd`、`~/.claude.json` 的 `projects` 键（正斜杠）、
  `~/.claude/history.jsonl` 的 `project`（反斜杠）。有独立的「预览命中」，每个被改文件都留 `.bak`。
- 备份/还原前请先关掉对应 CLI：运行中的 `*.sqlite-wal` / `-shm` 会复制到不一致快照。

## 运行（从源码）

需要 Python 3.9+，首次安装依赖：

```bash
pip install -r requirements.txt
```

然后双击 `启动.bat`，或命令行运行：

```bash
python app.py
```

## 打包成绿色版 EXE

双击 `build_exe.bat`（或见其内容）。产物在 `dist\会话转MD.exe`，为单文件、免安装、可拷走。

- 运行时依赖：**WebView2 运行时**（Win10/11 多数自带，随 Edge 提供）。
- 单文件模式首次启动会慢几秒（解压到临时目录），属正常现象。

## 目录结构

```
app.py            入口：Flask 后端 + pywebview 原生窗口
backend/
  parser.py       两种 JSONL → 统一事件流
  scanner.py      扫描目录、提取标题与 cwd（只读文件头，避免整读大文件）
  converter.py    事件流 + 模式 → Markdown
  migrator.py     事件流 → 轮次；写 Claude 会话 / Codex rollout / 通用交接包
  cli_registry.py 本机 AI CLI 目录注册表：自动探测、排除规则、体积测量
  vault.py        备份/还原引擎：干跑、后台任务与进度、manifest、四处路径改写
web/              前端界面（HTML/CSS/JS）
config.json       运行后生成：保存来源目录、输出目录、备份目录、自定义 CLI 目录
```

## 说明

- **大会话**：Codex 有的会话上百 MB，导出的 MD 也会很大；这类建议用「纯对话」模式。工具结果在非「完整原始」模式下会截断到 2000 字符。
- **Codex 去重**：Codex 在续跑/压缩时会重放历史用户消息，程序已折叠相邻重放，保留真正被隔开的重复输入。
- **Claude 去噪**：CLI 会把两类东西也写成会话记录 —— 本地命令回显（`<local-command-*>` / `<command-name>`）
  和它自己生成的提示（`model` 字段是 `<synthetic>`，如登录失败、`No response requested.`）。
  前者按噪音处理，后者按系统消息处理，都只在「完整原始」模式露出；
  API 报错后 CLI 重发的同一条指令（中间没有任何实际推进）也会折叠成一条。
- **源文件只读**：全程只读会话文件，导出与迁移都只新建文件；唯一会修改既有内容的是还原时的「路径改写」，默认关闭且有干跑与 `.bak` 留底。
- 配置文件 `config.json` 与 exe 同级，绿色版可整个文件夹/exe 拷走。
