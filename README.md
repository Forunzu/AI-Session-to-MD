# 会话转 MD

把 Claude CLI 与 Codex 的会话记录（JSONL）转换成 Markdown 归档，带图形界面：
浏览会话 → 预览内容 → 按重要程度逐条选导出模式 → 批量 / 单条导出。

## 下载

绿色单文件版在 [Releases](../../releases) 里下载 `会话转MD.exe`（约 21MB，免安装，双击即用）。
运行时仅依赖系统 **WebView2 运行时**（Win10/11 多数自带，随 Edge 提供）。

## 功能

- **自动读取**：启动即扫描默认目录（支持 `CLAUDE_CONFIG_DIR` / `CODEX_HOME` 环境变量），无需手动加载。
- **自定义来源**：会话不在默认位置时，可在「来源目录」里添加任意文件夹，自动识别 Claude / Codex 格式。
- **三种导出模式**（可逐条设置，也可批量设置）：
  - `纯对话`：只留你与 AI 的正文
  - `对话+工具`：正文 + 工具调用 / 命令 / 结果（默认）
  - `完整原始`：含思考、系统消息等全部内容
- **筛选与搜索**：按来源筛选、按标题/项目/日期搜索。
- **输出目录自选**：导出到你指定的目录，按 `claude/` `codex/` 分类，文件名为 `日期_标题.md`。

## 运行（从源码）

需要 Python 3.9+，首次安装依赖：

```bash
pip install -r requirements.txt
```

然后双击 `启动.bat`，或命令行运行：

```bash
python app.py
```

## 打包成绿色版 EXE

双击 `build_exe.bat`（或见其内容）。产物在 `dist\会话转MD.exe`，为单文件、免安装、可拷走。

- 运行时依赖：**WebView2 运行时**（Win10/11 多数自带，随 Edge 提供）。
- 单文件模式首次启动会慢几秒（解压到临时目录），属正常现象。

## 目录结构

```
app.py            入口：Flask 后端 + pywebview 原生窗口
backend/
  parser.py       两种 JSONL → 统一事件流
  scanner.py      扫描目录、提取标题（只读文件头，避免整读大文件）
  converter.py    事件流 + 模式 → Markdown
web/              前端界面（HTML/CSS/JS）
config.json       运行后生成：保存来源目录与输出目录
```

## 说明

- **大会话**：Codex 有的会话上百 MB，导出的 MD 也会很大；这类建议用「纯对话」模式。工具结果在非「完整原始」模式下会截断到 2000 字符。
- **Codex 去重**：Codex 在续跑/压缩时会重放历史用户消息，程序已折叠相邻重放，保留真正被隔开的重复输入。
- 配置文件 `config.json` 与 exe 同级，绿色版可整个文件夹/exe 拷走。
